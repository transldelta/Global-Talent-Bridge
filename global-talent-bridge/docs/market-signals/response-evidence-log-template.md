## How to add a new entry

Copy the template block below and fill in each field. Paste it at the bottom of this file, numbered sequentially.

```markdown
### Entry [N]

- **Date sent:** YYYY-MM-DD
- **Contact type:** buyer | pilot-customer | partner
- **Organisation:** [Name of organisation]
- **Contact person:** [First name or role title if name unknown]
- **Channel:** linkedin-dm | email | contact-form | warm-intro
- **Sent manually:** YES (must always be YES)
- **Response received:** Yes / No
- **Response date:** YYYY-MM-DD (leave blank if no response)
- **Interest level:** high | medium | low | neutral | no-response
- **Notes:** [What you sent. What they replied. Key phrases from their response.]
- **Shareable evidence:** Yes / No
- **Evidence link or description:** [Screenshot filename, email forward, LinkedIn message URL]
```

## What counts as market proof

For sale readiness purposes, the following scale applies:

| Evidence | Weight |
|---|---|
| Written response answering the proof question | ✅ Counts |
| Written expression of interest in follow-up call | ✅ Counts |
| Signed letter of intent (LOI) | ✅ Counts (strong signal) |
| Verbal conversation with no written record | ❌ Does not count |
| LinkedIn like or profile view | ❌ Does not count |
| Message marked as "read" without reply | ❌ Does not count |
| Test account interactions | ❌ Does not count |
| Your own test messages | ❌ Does not count |
