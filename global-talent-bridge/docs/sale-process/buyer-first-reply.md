*Sale Process · Buyer Response Kit · Admin use only*

## When to use this

Use this template when someone contacts you through a listing platform, LinkedIn, or email
expressing initial interest in acquiring CorridorWork.

**Before sending:** personalise `[Name]`, remove any brackets, and review the full message.
Send manually. No auto-send.

**Subject:** Re: CorridorWork — thank you for your interest

Hi [Name],

Thank you for reaching out about CorridorWork.

To be straightforward from the start:

**CorridorWork is pre-revenue.** There are no paying customers and no MRR. The
opportunity is an asset-based sale — not a revenue multiple — so the asking price
reflects the built infrastructure, not traction.

**What is included in the sale:**
- Live domain: corridorwork.com
- Full codebase (Next.js, TypeScript strict, Supabase, Vercel)
- Public-facing site: employer, candidate, partner, demo, and buyer pages
- Protected admin toolset and buyer-room documentation
- Documented transfer steps for all four assets (domain, GitHub repo, Vercel project, Supabase project)
- Latest lint, TypeScript, build, and test suite passed

**What is not included:**
- Revenue, customers, or signed agreements — none exist
- Staff or ongoing support beyond the handover process

If you have technical questions, I am happy to answer them in writing. I can share a
short buyer overview document as a first step, and provide deeper technical due-diligence
materials after confirmed mutual interest.

No obligation and no pressure.

Kind regards,

## Notes for the founder

- If they ask about revenue: answer honestly — €0 MRR, 0 customers, pre-revenue asset stage.
- If they ask about transfer time: do not give a fixed number of days. Say it depends on domain,
  GitHub, Vercel, Supabase, and their own account setup. Documented handover steps exist.
- If they ask for admin access or credentials: decline until a serious process (NDA or escrow)
  is in place. See `red-lines.md`.
- If they want to make an offer quickly: welcome it in writing. Refer them to the buyer package
  at corridorwork.com/for-buyers for full context.
