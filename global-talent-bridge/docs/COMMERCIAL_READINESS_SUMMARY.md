## Was fehlt für echten Umsatz

### Sofort notwendig (wenn Umsatz starten soll)

| Was | Aufwand | Priorität |
|---|---|---|
| Echtes Lead-Outreach-System aktivieren | EMAIL_PROVIDER ändern | Hoch |
| Stripe / Payment aktivieren | Stripe-Keys, Checkout | Hoch |
| Kandidaten-Datenbank aufbauen | DB + Matching-Logik | Hoch |
| AGB / Widerrufsrecht vervollständigen | Anwalt oder Template | Mittel |
| AÜG / Rechtsprüfung (Arbeitnehmerüberlassung) | Anwalt | Hoch (DE-Pflicht) |
| Google-Indexierung abwarten | Zeit + SEO | Mittel |

### Mittel-/Langfristig

| Was | Beschreibung |
|---|---|
| Market Validation | Echte Employer-Interviews, Pilotpartner gewinnen |
| Matching-Logik | Kandidaten ↔ Employer automatisch matchen |
| Onboarding-Flows | Employer-Onboarding, Kandidaten-Onboarding |
| AÜG-Lizenz oder Partnermodell | Für legales Arbeitnehmerüberlassung-Geschäft |
| Marketing / SEO | Google-Indexierung, Backlinks |

## Schnellster legaler Weg zu erstem Umsatz

**Rang 1: Strategic Partnership / Acquisition (sofort)**

Ein einziger Deal (White-Label, Lizenzing oder Asset-Kauf) generiert sofort Umsatz ohne operative Infrastruktur.
- Seite live: `/strategic-partnership`
- Lead-Formular funktioniert
- **Kein Stripe nötig** — Zahlung per Rechnung/Überweisung

**Rang 2: Agency Partner (1–4 Wochen)**

Recruiting-Agenturen können sofort als White-Label-Partner eingebunden werden.
- Seite live: `/partners`
- Kein AÜG-Problem wenn Agentur das operative Matching übernimmt

**Rang 3: Employer Pilot (4–8 Wochen)**

Direkte Pilot-Partnerships mit Arbeitgebern in DE/EU.
- Seite live: `/pilot/employers`
- Rechtliche Prüfung für AÜG empfohlen vor Go-Live
