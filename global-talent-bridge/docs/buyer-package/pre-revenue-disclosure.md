## Why the platform still has value at €0 revenue

An asset-stage SaaS acquisition is priced on infrastructure value, not revenue history.

The comparable question is: **how much would it cost to build this from scratch?**

| Component | Build cost estimate |
|---|---|
| Next.js App Router with TypeScript strict, 4 352 tests | €15 000–€30 000 |
| Supabase schema with RLS, GDPR, EU hosting | €5 000–€10 000 |
| 8-corridor intelligence engine with Buyer Opportunity Scores | €10 000–€20 000 |
| Admin toolset (10+ tools including Buyer Room, Growth Dept, Contact Copilot) | €20 000–€40 000 |
| 25+ SEO landing pages with structured data | €5 000–€15 000 |
| 50+ documentation files (architecture, security, transfer, valuation) | €5 000–€10 000 |
| Live domain + Vercel + Supabase infrastructure | €500–€2 000 |
| **Total rebuild estimate** | **€60 500–€127 000** |

The current realistic asking range (€15 000–€25 000) is **below the estimated rebuild cost** for a buyer who would need to build this from scratch. Higher ranges (€30K–€69K+) require documented buyer signals or real MRR — see [`asking-price-rationale.md`](./asking-price-rationale.md).
