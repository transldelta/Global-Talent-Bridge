# CorridorWork — Support Boundaries

**What the Seller Will and Will Not Support After Transfer**

---

## Seller Support Scope

Support is available during the **Inspection Period only** (typically 14–30 days as agreed in the purchase agreement) and is limited to the following:

### What Seller Will Support

| Type | Detail |
|---|---|
| Core technical transfer | Handing over GitHub repository, domain transfer guidance |
| Setup clarification | Answering questions about `.env.example` variable names and purpose |
| Documentation questions | Clarifying anything in `docs/` or this transfer package |
| Obvious defects | If a documented feature is clearly broken as-transferred (not due to buyer changes) |
| One-time handover call | Optional — 30–60 min video call to walk through the repository |

### What Seller Will NOT Support

| Type | Why |
|---|---|
| Buyer's own modifications | Any changes the buyer makes are their responsibility |
| New feature development | Not included — buyer commissions this from a developer |
| Deployment service | Buyer uses their own Vercel account and manages their own deployment |
| Supabase / database setup | Buyer creates and manages their own Supabase project |
| Business operations | Platform comes with 0 customers — buyer is responsible for acquisition |
| Revenue generation | Seller makes no guarantee of revenue outcome |
| Customer acquisition | Not included — buyer's responsibility |
| Email / outreach activation | Buyer activates and configures their own email provider |
| Payment / Stripe setup | Buyer implements payment flows with their own developer |
| SEO or marketing | Buyer manages their own SEO strategy |
| Ongoing maintenance | Post-Inspection Period, seller has no obligations |
| Legal / compliance advice | Buyer must consult their own lawyer for applicable regulations |
| GDPR compliance | Buyer is responsible for data protection compliance under new ownership |
| Support for forked versions | If buyer forks or substantially modifies the code |
| Third-party integrations | Any tools buyer adds (analytics, CRM, etc.) |

---

## Post-Inspection Period

After the Inspection Period ends, **no seller support is provided** unless explicitly agreed in a separate paid support agreement.

---

## Guarantees Explicitly Not Made

The seller makes **no guarantee** of:

- Any revenue, MRR, ARR or business performance
- Customer acquisition under new ownership
- Employment outcomes for candidates
- Visa approval or immigration outcomes
- Job placements of any kind
- Platform uptime (buyer manages their own Vercel deployment)
- SEO rankings or organic traffic
- Fit for any specific business purpose
- Compliance with laws in the buyer's jurisdiction

---

## Bug Reports During Inspection Period

If the buyer identifies a genuine defect in the transferred platform **as-transferred** (before any buyer modifications):

1. Buyer documents the issue with steps to reproduce
2. Buyer contacts seller via agreed channel
3. Seller reviews within 5 business days
4. If confirmed as a pre-transfer defect: seller provides a fix or guidance
5. If the issue is caused by buyer's own setup, modifications or third-party services: outside scope
